Syllabus Unit Coverage

Each unit of the syllabus is demonstrated through hands-on AWS work.

Unit 1
Linux & Virtualization
Deployed app on EC2 using Amazon Linux 2023. Managed file permissions, processes, systemd services, SSH key-based auth, and Gunicorn setup.
SSHsystemd chmod/chownEC2
Unit 2
Networking
Configured VPC with public/private subnets, CIDR blocks, Internet Gateway, route tables, and Security Groups on ports 22, 80, and 443.
VPCCIDR Security GroupsDNS
Unit 3
Cloud Fundamentals
Compared IaaS (EC2) vs PaaS (Render) vs SaaS. Applied AWS shared responsibility model and designed for elasticity with stateless frontend.
IaaSPaaS Shared Responsibility
Unit 4
Core AWS Services
Used EC2, S3 (static hosting + file storage), IAM (users/roles/policies), VPC, and CloudWatch. Compared to Azure VM and Azure Blob Storage.
EC2S3 IAMCloudWatch
Unit 5
DevOps, Git & Monitoring
GitHub repo with branch-based workflow, GitHub Actions CI/CD auto-deploying to S3. CloudWatch agent monitors EC2, billing alerts configured.
GitHub ActionsCI/CD CloudWatchBilling Alerts
