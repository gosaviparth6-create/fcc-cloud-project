Unit 1, 2, 4 · EC2 API Backend
Flask Contact API on EC2

A hardened REST API running on Amazon EC2 (Amazon Linux 2023) behind Nginx as a reverse proxy. Handles contact form submissions, PDF uploads to S3, admin authentication with signed JWT-style tokens, rate limiting, and structured JSON logging via CloudWatch Agent.

🐧 EC2 (t2.micro) with Amazon Linux 2023, SSH key-pair
🔀 Nginx reverse proxy (port 80/443 → Gunicorn 8000)
🐍 Flask API with rate limiting (flask-limiter)
🔑 Signed bearer tokens (itsdangerous, SHA-256, 1hr expiry)
🗄️ S3 PDF upload with AES-256 server-side encryption
🌐 VPC: public subnet, SG ports 22/80/443 only
EC2 (t2.micro) Nginx Flask + Gunicorn S3 (uploads) IAM Role CloudWatch Agent PostgreSQL / SQLite VPC + SG

EC2 Linux Server Configuration

Documented setup of an EC2 Linux server from scratch — SSH access, user management, systemd service management, firewall rules, VPC networking, and SSL certificate provisioning with Let's Encrypt. Demonstrates core Linux and networking skills required by the syllabus.

🔐 SSH key-pair auth, no password login
